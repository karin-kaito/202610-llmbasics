nn.Linear 早見表

PyTorch の全結合層が中で何をしているかを、形（shape）で押さえるための 1 枚です。例はすべて Linear(50, 30)：入力 50 個から出力 30 個を作る層です。

まず覚える 3 つ

  1. weight の形は (出力, 入力) = (30, 50)。 1 行が、出力ニューロン 1 個ぶんの重み（入力 50 個ぶん）です。
  2. 計算は X @ W.T + b。 データは「1 件 = 1 行」で入ってくるので、.T で W の向きを合わせます。
  3. 変わるのは最後の次元だけ。 (…, 50) → (…, 30)。前の次元（件数・トークン数）はそのまま通ります。パラメータ数は 入力×出力＋出力 = 1,530。

図 1形の掛け算：内側がそろい、外側が答えになる

図 2W の 1 行 = 出力ニューロン 1 個に入る線

y[0, 0] = X[0,0]·W[0,0] + X[0,1]·W[0,1] + … + X[0,49]·W[0,49] + b[0] ⇔ (X[0] * W[0]).sum() + b[0]

表入れる形と出てくる形

入力 X の形出力 y の形どんな場面か
(1, 50)(1, 30)1 件だけ（下のコード）
(5, 50)(5, 30)5 件まとめて（バッチ）
(2, 4, 50)(2, 4, 30)(バッチ, トークン数, 次元)。③ ch03〜04 の Attention や GPT でこの形になる

どの行も、最後の 50 が 30 に変わるだけです。3 行とも torch 2.15.0 で実行して確認しました。

コード自分で確かめる 1 セル

a5.py に貼る（# %% から 1 セル）
# %%
import torch

torch.manual_seed(123)
layer = torch.nn.Linear(50, 30)
W, b = layer.weight, layer.bias
X = torch.rand((1, 50))

y1 = layer(X)                 # PyTorch に計算させる
y2 = X @ W.T + b              # 自分で計算する（.T で向きを合わせる）
print(y1.shape, y2.shape)
print(torch.allclose(y1, y2)) # 同じ値か？

# 出力ニューロン 0 番 = W の 0 行目（50 個）と入力の掛け算の合計 + b[0]
y0 = (X[0] * W[0]).sum() + b[0]
print(y0.item(), y1[0, 0].item())
print(W[0].shape)
